Retrieval-augmented generation (RAG) is a technique that grants generative artificial intelligence models information retrieval capabilities.

It modifies interactions with a large language model (LLM) so that the model responds to user queries with reference to a specified set of documents, using this information in return to augment information drawn from its own vast, static training data.

This allows LLMs to use domain-specific and/or updated information. Use cases include providing chatbot access to internal company data, or providing factual information only from an authoritative source.
